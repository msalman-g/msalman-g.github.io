About me

Full-stack engineer, end to end, AI-curious.

I'm a Full-stack & AI Software Engineer based in Lahore, Pakistan, with 6+ years building production web applications. I'm currently an L4 Software Engineer at Motive, a Forbes 100 fleet-management company, where I own features end-to-end across React/Angular frontends and a Ruby on Rails + Node.js backend.

Alongside my core role, I've built and shipped an AI Coach — a production LLM system that generates personalised driver-coaching videos at scale using prompt engineering, OpenRouter, Airflow and HeyGen — plus a string of independent full-stack projects spanning proptech, healthtech and fintech.

I care most about clean, well-tested systems — from the UI down to the database — and about connecting engineering work to real business outcomes: conversion, engagement, and revenue, not just ship counts.

I can't dance, sing, or play video games, and I'm definitely not an athlete. All I know and have been doing for 10+ years now is coding, and I'm pretty happy about that.
